---

**Ygaraty is an open-source framework for distributed computation.** We are
building the pieces that let any kind of mathematical computation run across
heterogeneous devices and networks, with compute contributed by one person or
by many collaborators.

A laptop's integrated GPU, a gaming desktop, a friend's machine across the
city: each can join a computation from a browser tab or the command line, and
together they can do what none of them could alone.

### What we build

- **Compiler and analyzer** — describe a computation once and plan how to split
  it across the devices that are available.
- **Tape and execution engine** — reusable building blocks for running that
  plan over browser or native WebGPU workers.
- **Inference today** — chat with open models running on one GPU or shared
  across several, from your terminal, a browser, or any OpenAI-compatible app.
- **Training as open research** — distributed training, including DiLoCo, is
  an ongoing public research effort with methods, results and limitations
  published as we go.

### How we work

We build in the open: compiler, analyzer, runtime, tape, training code and
research. Every claim comes with measurements someone else can check, and
limitations are written down next to the results.

Bring an experiment, a new backend, a benchmark, a bug fix or a better
explanation. Small contributions are welcome — give them a clear purpose and
enough evidence for someone else to build on them.
